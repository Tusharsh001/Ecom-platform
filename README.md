AI-Enabled E-Commerce Platform

This project is a full-stack e-commerce web application built using Java, Spring Boot, Spring AI, REST APIs, MySQL, and React. The system provides modern e-commerce features such as product catalog management, user authentication, shopping cart, checkout, payment workflow, and inventory tracking. Additionally, it integrates Spring AI to generate product descriptions and assist users with AI-driven order tracking and customer support.

🚀 Features

✔ Product Catalog Management
• Add, update, delete, and view products
• AI-generated product descriptions using Spring AI
• Product image storage & retrieval

✔ User Management
• Account creation & authentication
• Profile data persistence
• Session handling & authorization

✔ Shopping Cart & Checkout
• Add/remove products from cart
• Price calculation & quantity updates
• Secure checkout and payment workflow

✔ Inventory Management
• Real-time stock updates
• Product availability validation

✔ AI-Assisted Help Desk(yet to be added)
• Order status inquiries via AI
• Automated support responses
• Natural language interaction
